# SUIVI-ECO

Pages publiques de suivi de l'economie francaise du compte GuillaumePoignet.

## Ce que contient ce depot
Le code des pages, et rien d'autre. Aucune serie, aucun chiffre,
aucune note, aucune donnee du socle.

## Ce qu'il ne contient pas
Les donnees vivent dans le depot prive GuillaumePoignet/DEPOT-AGENT-ECO.
La page ouverte dans le navigateur du proprietaire y accede avec sa cle
de lecture GitHub, collee a la main. Sans cette cle, GitHub repond
" introuvable " : ce depot public ne donne acces a rien.

Modele repris de SUIVI-BOURSE, lui-meme repris de jlucb67.github.io/CONSOLE/.

## Pages
- index.html : l'entree, huit rubriques.
- vue-densemble.html : la premiere rubrique en ligne. Elle lit cinq
  fichiers du depot prive : produit interieur brut, decisions de taux
  de la BCE, escompte 1800-1990, change annuel de l'euro, points recents
  (inflation, emprunt d'Etat a 10 ans, credits bancaires, change du jour).
